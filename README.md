# coursework_SVF
Репозиторий курсовой работы:

> **«Взаимосвязь лингвистических характеристик семантической вербальной беглости у пожилых людей с их когнитивным статусом (объективным и по данным самооценки)»**

**Выполнила:** Липина Ангелина, НИУ ВШЭ, ОП "Фундаментальная и компьютерная лингвистика"  
**Научный руководитель:** Черкасов Н. С., к.м.н., младший научный сотрудник, Центр языка и мозга  

---

Репозиторий содержит файлы с кодом, использованным в ходе выполнения курсовой работы:

- `answers_metrics.ipynb`  
  Алгоритм лемматизации и кластеризации ответов на тест семантической вербальной беглости  

- `model.ipynb`  
  Модель логистической регрессии для классификации пациентов на клинические группы в соответствии с их когнитивным статусом  

- `statistics.ipynb`  
  Алгоритмы для анализа демографических и клинических данных пациентов
